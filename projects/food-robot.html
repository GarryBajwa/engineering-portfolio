Food-Serving Mobile Robot

Android destination selection integrated with a SLAMTEC navigation stack so a user could choose a table and send the robot to that location autonomously.

Food-Serving Mobile Robot Android destination selection connected to LiDAR mapping, localization and autonomous navigation.

Engineering objective

Turn the existing SLAMTEC navigation capability into a simple table-selection workflow that a user could operate from an Android interface.

My contribution

I developed the Android-side interface and communication integration used to send selected table destinations into the robot navigation workflow.

Validation outcome

Destination commands were demonstrated on the SLAMTEC development platform through X/Y positioning and final yaw adjustment, followed by operation of the completed food-serving robot in a restaurant environment.

Data flow

Android Table Selection→Ethernet / IP Communication→ SLAMTEC Navigation→LiDAR + Encoders→Autonomous Motion
Project overview

The mobile platform already provided SLAMTEC mapping and navigation capability, but it needed a practical operator workflow for restaurant use. I developed the Android-side destination interface and communication integration that connected table selection to the robot’s existing autonomous navigation stack.

Integration problem

Turning a navigation platform into a simple user workflow

The technical value was not just autonomous navigation. The goal was to bridge the navigation hardware/software with a practical table-selection interface a user could operate directly.

Interface

User actionSelect the destination table in the Android application.
Command handoffThe application communicated the selected destination to the robot over the network using the SLAMTEC integration path.

Autonomous navigation

LocalizationLiDAR mapping/localization and wheel-encoder feedback supported awareness of the robot’s position within the mapped environment.
Pose validationThe SLAMTEC development platform was tested by sending a destination from the Android GUI, navigating to the commanded X/Y position, and then adjusting yaw/orientation to reach the requested final pose.
