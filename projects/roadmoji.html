Roadmoji Vehicle Display Controller Raspberry Pi + Stream Deck prototype combining physical controls, full-screen media and a web management interface.

Engineering objective

Create a low-distraction physical control system for triggering temporary or persistent rear-display messages without navigating a conventional touchscreen interface.

My contribution

I developed the Raspberry Pi software, Stream Deck interaction logic, PyQt full-screen renderer and Flask-based media-management workflow.

Prototype outcome

The bench-tested prototype supports short-press temporary messages, long-press default selection and browser-based media management. It is not represented as a completed in-vehicle deployment.

Interaction path

Stream Deck Button→Python Event Logic→ PyQt Full-Screen Renderer→HDMI Display
Project overview

Roadmoji is a personal embedded-systems prototype exploring low-distraction control of a rear vehicle display using physical Stream Deck buttons. I built the Raspberry Pi software stack for button events, full-screen media rendering, persistent default selection and browser-based media management.

Design goals

Fast physical control with low operator distraction

Button behavior

Short pressDisplays the selected media temporarily, then returns to the default image.
Long pressSets a selected media item as the persistent default/main image.

Media management

Web uploadA Flask interface supports adding or changing media without editing code on the Raspberry Pi.
Automatic mappingMedia files are discovered and mapped to the Stream Deck button layout for practical use.

Reliability improvements

StartupThe application is designed to launch automatically on boot rather than rely on manual desktop interaction.
Device recoveryOngoing work addresses USB/Stream Deck reconnection and feedback behavior when the device is unplugged/reconnected.
