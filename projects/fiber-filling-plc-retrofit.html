Fiber Filling Machine — Relay Logic to Siemens S7-1200 PLC Retrofit

Converted a sequence-sensitive relay-controlled fiber filling machine into a PLC-controlled system with automatic timing, simplified operator controls and an added emergency-stop function.

Siemens S7-1200PLCRelay LogicVFDStar-DeltaMachine Retrofit
Controls modernization Manual relay sequencing was replaced by PLC-controlled startup, shutdown and timing while retaining the machine’s useful manual feeder functions.

Engineering objective

Make the machine easier to operate and less dependent on operator timing while reducing sequence-related resets, fiber jams and relay-logic troubleshooting complexity.

My contribution

I reviewed the existing relay-controlled sequence, mapped the machine loads and control outputs, selected the PLC/output architecture, rewired the control system and programmed the startup, shutdown and timing logic.

Control architecture

Siemens S7-1200 PLC with one digital output expansion module controlling five contactor functions, two VFD run commands and one solenoid valve.

Control concept

Power Toggle→ Start / Stop→ S7-1200 Sequence Logic→ Contactors + VFD Runs→ Motors / Feeders / Solenoid
Project overview

The original machine required the operator to manually execute a strict multi-button startup and shutdown sequence. I replaced the relay-based sequencing with a Siemens S7-1200 PLC so the machine could execute the required order and delays automatically from simple Start/Stop controls while preserving the manual feeder and direction functions operators still needed.

01 · Operating problem

The machine depended on the operator performing the sequence correctly every time

The original control system worked, but normal operation depended heavily on button order and timing.

Manual startupThe operator used five ON controls: main power followed by stages 1 through 4 in sequence.
Manual shutdownStopping required the reverse sequence: stage 4 back through stage 1, then main power OFF.
Sequence sensitivityIf a button was missed or the timing between steps was wrong, the machine could require a reset and complete restart.
Material consequenceIf fiber was already inside the machine when the sequence failed, material could become stuck and create additional recovery work.
The core problem was not simply “too many buttons.” The process sequence itself belonged in the controller rather than in the operator’s memory and timing.

02 · PLC control redesign

Move the sequence from manual button timing into deterministic PLC logic

I simplified the operator interface while preserving the controls that still provided useful manual functionality.

Simplified operationThe main operating workflow became a power ON/OFF toggle plus Start and Stop pushbuttons.
Programmed sequencingThe PLC executes the required machine sequence and inter-stage delays automatically rather than relying on manual timing.
Manual feeder controls retainedOne manual feed button for each feeder remained available because those functions were still useful to the operator.
Direction control retainedThe existing shared forward/reverse selector for the feeder system remained part of the operator controls.
Emergency stop addedAn emergency-stop control was added during the retrofit; the original machine did not have one.
Diagnosis simplifiedCentralizing the sequence in the PLC reduced the amount of distributed relay logic that had to be followed when diagnosing a control problem.

03 · Panel architecture & I/O

Eight outputs covered the machine’s contactors, VFD commands and door solenoid

Before choosing the PLC hardware, I mapped the existing machine functions and counted the outputs required by the retrofit.

Motor and load control

Fiber opener motorSix motor leads were used for star-delta operation. Two contactors were dedicated to the star/delta switching portion of this motor control.
Second three-phase motorControlled through one contactor.
Blower fanControlled through one contactor.
Main ON/OFF contactorOne additional contactor handled the main control/power function, bringing the total contactor-controlled outputs to five.

Additional outputs

Feeder 1 VFDThe existing VFD already handled the feeder motor drive function, so the PLC only needed to provide its run command.
Feeder 2 VFDThe second feeder VFD similarly required a PLC run command rather than replacement of the drive.
Door solenoidOne PLC output operated the solenoid valve used for the machine door function.
Total output requirementFive contactor functions + two VFD run signals + one solenoid valve = eight outputs.

Output allocation

5 × Contactor Functions+ 2 × VFD Run Signals+ 1 × Solenoid Valve= 8 PLC Outputs
This output count drove the hardware choice: an S7-1200 PLC plus one digital output expansion module provided the required control points without changing the existing VFD-driven feeder architecture.

04 · Result

A machine that was easier to run, easier to recover and easier to troubleshoot

Operator workflowThe normal machine sequence no longer depended on the operator remembering and timing multiple ON/OFF steps.
Repeatable timingRequired delays became programmed values executed consistently by the PLC.
Fewer sequence errorsSimplified Start/Stop operation reduced the opportunities for missed or delayed manual sequence steps.
MaintainabilityThe control sequence became centralized and easier to follow than the previous distributed relay logic.
Existing hardware reusedThe two feeder VFDs remained in service, with the PLC providing the run commands needed by the updated control scheme.
Safety improvementThe retrofit added an emergency-stop operator control that had not been present on the original machine.
