## Before uploading

- Use PNG with exactly the filenames above (or update references in the project page and `projects-data.js`).
- Suggested canvas: **1600 × 1000** or **1600 × 900** pixels; diagrams can be wider. PNG is preferred for readable text.
- **No proprietary application code, unmasked employee or customer data, confidential production data, internal paths, credentials, or company-specific access details.**
- Concept screens use sample data and are clearly identified on the page; they should not be described as deployed UI evidence.
- The central production system used Excel-backed workbooks; do not depict a SQL database as its deployed backend.
- Label the Tag PDF Manager and CAD/CAM tools as **related applications** unless a particular direct integration is confirmed.

Two additional colour-coded, cross-referenced engineering schematics are available as PNG and editable SVG in the delivery package. The built-in HTML architecture and ecosystem diagrams are already visible even before these images are uploaded.
